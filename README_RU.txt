БОЛГАРКА - мод для Minecraft 1.21.1 (NeoForge)

КАК СОБРАТЬ (нужна Java 21):
  Windows:   открой cmd в этой папке:   gradlew.bat build
  Linux/Mac: ./gradlew build
Готовый мод: build/libs/bolgarka-1.0.0.jar  ->  в папку .minecraft/mods

КРАФТ БОЛГАРКИ:
  Железо   Точило          Железо
  Медь     Блок редстоуна  Медь
  -        Железо          -
Болгарка идёт с железным диском внутри.

КАК ПИЛИТЬ: болгарка в руке, наведи на моба, ЗАЖМИ левую кнопку мыши.

КАК МЕНЯТЬ ДИСК: болгарка в основной руке, нужный диск в ЛЕВОЙ руке (F), нажми ПКМ.
Старый диск вернётся в инвентарь.

ДИСКИ (формы крафта: диск в центре, материал по сторонам - плюсом):
  Железный    железо x4 + кремень в центре          базовый, урон 2
  Золотой     золото x4 + железный диск             слабый, но +опыт за убийство
  Алмазный    алмазы x4 + железный диск             урон 4
  Пильный     нагетсы в углах, кремень по сторонам, железный диск в центре
                                                    КРОВОТЕЧЕНИЕ (до 3 уровней), конечности отваливаются от кровопотери
  Огненный    стержни ифрита x4 + железный диск     поджигает
  Вампирский  слеза гаста сверху, 3 бродильных глаза паука + железный диск  лечит тебя
  Незеритовый обломки незерита x4 + алмазный диск   урон 6, кровотечение, не горит

Выдать в креативе: /give @s bolgarka:angle_grinder , /give @s bolgarka:saw_disc и т.д.
